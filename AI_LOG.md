# Отчет об использовании ИИ

**Инструмент:** ChatGPT

### Промпты и контекст:

1. **Промпт:** "Сгенерируй мок-данные для дашборда запусков на React. Нужно 6 объектов: id, name, repository, branch, status (queued/running/succeeded/failed), createdAt, durationSeconds, logs."

   *Контекст:* Я передал модель данных из ТЗ. ИИ отлично справился, я лишь немного поправил даты, чтобы они были в ISO формате.
2. **Промпт:** "Как в React отфильтровать массив по двум условиям (поиск по строке и фильтр по статусу)?"

   *Контекст:* ИИ предложил использовать `useMemo` и метод `filter`. Я адаптировал его код под свои стейты `searchQuery` и `statusFilter`.
3. **Промпт:** "Накидай базовые CSS стили для списка карточек и модального окна. Нужен молочный фон и темно-синие акценты."

   *Контекст:* Я скинул ИИ структуру своих JSX-компонентов (классы), чтобы он сгенерировал подходящий CSS. ИИ выдал довольно объемный код с лишними анимациями и сложными тенями. Я упростил стили, оставив только нужный Flexbox и простые цвета, чтобы не перегружать проект.
